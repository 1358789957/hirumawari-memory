## 库乐队怎么导

**iPhone / iPad**

1. 用 Safari 打开上面的 MIDI 链接，选「下载」→ 存到「文件」
2. 打开库乐队 → 新歌曲 → 键盘
3. 把速度改成 **117**
4. 点右上角循环 →「文件」→ 选 MIDI → 拖进音轨
5. 人声 WAV 同样拖进来当音频轨

**Mac**

把 `.mid` 直接拖进库乐队窗口。速度一般会读成 117。

对不上口型的话，把工程速度改成 88 或 78 再听一遍。

开头旋律：`G4 A4 B4 A4 B4 C5 B4 A4`

和弦进行见 [CHORDS.md](./CHORDS.md)。
词谱（上音符 / 中歌词 / 下和弦）见 [昼回のメモリー-词谱.txt](./昼回のメモリー-词谱.txt)。
